# Skills

Collection of my custom skills.

## Install

```bash
npx skills@latest add olivierestevez/oli-skills
```

## Reference

- **/create-ae-plugin**: Build After Effects custom effect plugins in C++ following best practices and with the AE SDK.
- **/create-ae-pseudo-effect**: Create After Effects pseudo effects (custom Effect Controls panels for scripts and rigs) as `.ffx`.
- **/export-video**: Collection of best practices and workflows to export high-quality video in the browser (MP4 and MOV).
